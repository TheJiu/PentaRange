# 🎯 [CyberRange]

> 一个专为网络安全爱好者和渗透测试初学者打造的综合性漏洞靶场。无需复杂配置，一键启动，安全地体验和学习各种漏洞的利用与防御。

## ✨ 靶场特性 (Features)
- **覆盖全面**：包含 OWASP Top 10 常见漏洞（SQL注入、XSS、文件上传、RCE、SSRF、反序列化等）。
- **环境隔离**：基于 Docker 容器化部署，不污染宿主机环境。
- **难度分级**：每个漏洞场景分为 Low / Medium / High 三个难度，适合循序渐进学习。
- **通关指引**：每个关卡自带目标提示和修复建议。
